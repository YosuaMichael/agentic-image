# Code of Conduct

Be kind, be honest, give credit. This project welcomes contributors of all
backgrounds and skill levels; harassment, plagiarism, or passing off others'
work (including model-generated output) as your own is not tolerated.

Attribute upstream work (Ideogram 4, Qwen, Hive) wherever it appears, and
respect the Non-Commercial terms on Ideogram 4 weights and output.
